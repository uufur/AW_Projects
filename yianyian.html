    🔄 如何更新账号数据

    1. 使用 playwright-scraper 或 xhs-creator-content-research skill 抓取最新主页数据
    2. 把新抓取的 JSON 整理为本驾驶舱格式，追加到 数据/latest.js 的 snapshots 数组末尾
    3. 同时归档一份到 数据/snapshots/snapshot-YYYY-MM-DD.js，便于历史回溯
    4. 刷新本页面，所有图表与诊断会自动重新计算

    📋 如何更新策略执行进度

    1. 每发布一条笔记，编辑 数据/strategy.js，更新对应 plan 项的 status 和 actualLikes / actualSaves / actualComments / actualViews
    2. 状态枚举：选题 → 脚本中 → 待拍摄 → 已拍摄 → 已发布
    3. 刷新本页面，KPI 仪表盘与进度条会自动更新

    📁 项目结构

    1. 驾驶舱/index.html — 本文件，数据可视化主入口
    2. 数据/latest.js — 账号数据快照（多份历史快照）
    3. 数据/strategy.js — 策略执行规划（置顶/选题/KPI）
    4. 数据/snapshots/ — 历史快照归档
    5. 策略/ — 5 份详细策略文档（定位/选题/爆款/日历/KPI）
    6. 复盘/ — 周/月复盘记录
    7. 选题库/topics.json — 选题池
